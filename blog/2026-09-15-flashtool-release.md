# Hi,

As you've known, the last few months have been met with a lot of delays and frustrating things for the MP01. I'll start off this post with a simple message.

**We're still pushing to release the update officially.**

In the mean time for those who don't want to wait, we've now launched the [Minimal flashtool](https://flash.minimalcompany.dev)!

Here you're able to update your device to the latest beta OTAs over WebUSB (supported browser required), personally I've been using [Helium](https://helium.computer), but most Chromium based browsers work, even Chrome running on another MP01!

This is the first time I've released something like this, so forgive me if there's any downtime or bugs in the installer, if you have any issues, reach out via the Discord or the link on the flashtool and I'll help you out!

Check it out! -> https://flash.minimalcompany.dev

As always, backup before you proceed, and enjoy!

-Charlie
